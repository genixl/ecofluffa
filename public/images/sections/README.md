## Image Features
- All images have **hover zoom effect** (scales to 1.08 on hover)
- All images have **shadow enhancement** on hover (dark mode friendly)
- Images are **theme-aware** and look good in both light and dark modes
- Background placeholders show while images load
- Images are **responsive** and adapt to all screen sizes

## How to Add Images
1. Simply replace each placeholder image with your own image
2. Keep the same filenames to avoid updating code
3. JPEG, PNG, and WebP formats are supported
4. For best results, use high-quality images optimized for web
